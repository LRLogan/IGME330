About This App

- The divergence angle can be set in the pulldown menu above
- The restart button will clear the screen and reset the pattern
- The framerate slider will adjust how fast the pattern is drawn. (Default is now 60 FPS)
- The circle radius slider will adjust the size of the circles drawn for each point (Default is 2)
- The fade checkbox will enable or disable the fading trail effect The changes made from the starter code include
- Added UI controls for divergence angle, framerate, circle radius, and fade effect
- Implemented the phyllotaxis pattern using the formula for angle and radius
